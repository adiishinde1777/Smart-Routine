# ⚡ ESP8266 + RTC Module + 3 LEDs पिन जोडणी (Pin Summary)

खालील तक्ता तुमच्या इमेजप्रमाणे तंतोतंत जोडलेला आहे:

---

## 📌 अंतिम पिन जोडणी तक्ता (Exact Matching Chart)

| घटक (Component) | ESP8266 Pin | तपशीलवार कनेक्शन पद्धत |
|---|---|---|
| **LCD SDA** | **D2** | 16x2 I2C LCD ची SDA पिन |
| **LCD SCL** | **D1** | 16x2 I2C LCD ची SCL पिन |
| **RTC SDA** | **D2** | DS3231/DS1307 RTC ची SDA पिन (LCD SDA सह D2 वर) |
| **RTC SCL** | **D1** | DS3231/DS1307 RTC ची SCL पिन (LCD SCL सह D1 वर) |
| **RTC VCC** | **3V3** | RTC ची 3.3V पॉवर पिन |
| **RTC GND** | **GND** | RTC चा ग्राउंड |
| **Buzzer +** | **D0** | बझरचा लाल/पॉझिटिव्ह (+) पाय D0 ला |
| **Buzzer –** | **GND** | बझरचा काळा/निगेटिव्ह (-) पाय GND ला |
| **LED 1 +** | **D5** | 220Ω रेझिस्टरद्वारे D5 ला (Slot 1 / कप्पा १) |
| **LED 2 +** | **D6** | 220Ω रेझिस्टरद्वारे D6 ला (Slot 2 / कप्पा २) |
| **LED 3 +** | **D7** | 220Ω रेझिस्टरद्वारे D7 ला (Slot 3 / कप्पा ३) |
| **सर्व LED –** | **GND** | तिन्ही LEDs चे निगेटिव्ह (-) पाय एकत्र GND ला |
| **Push Button** | **D4 आणि GND** | बटणाचा एक पाय D4 ला, दुसरा पाय GND ला |

---

## 💡 मुख्य वैशिष्ट्ये व कार्य:
1. **I2C Bus Sharing (D1 & D2):**
   - LCD आणि RTC दोन्ही I2C वापरतात.
   - LCD चा SDA आणि RTC चा SDA दोन्ही **D2** ला एकत्र जोडायचे.
   - LCD चा SCL आणि RTC चा SCL दोन्ही **D1** ला एकत्र जोडायचे.
2. **३ स्वतंत्र LEDs (D5, D6, D7):**
   - **औषध १ ची वेळ झाल्यास:** फक्त **LED 1 (D5)** ब्लिंक होईल.
   - **औषध २ ची वेळ झाल्यास:** फक्त **LED 2 (D6)** ब्लिंक होईल.
   - **औषध ३ ची वेळ झाल्यास:** फक्त **LED 3 (D7)** ब्लिंक होईल.
   - **दोन औषधे एकाच वेळी असल्यास:** दोन्ही संबंधित LEDs (उदा. D5 आणि D6) **एकाच वेळी एकत्र ब्लिंक होतील!**
3. **Push Button (D4 आणि GND):**
   - अलार्म वाजत असताना D4 वरील पुश बटण दाबताच चालू असलेले सर्व LEDs आणि Buzzer एकाच झटक्यात बंद होतील.
4. **घड्याळ (DS3231 RTC):**
   - अलार्म चालू नसताना LCD च्या दुसऱ्या ओळीवर **खऱ्या घड्याळाची वेळ (उदा. `12:45:10 Ready`)** लाईव्ह दिसेल.
